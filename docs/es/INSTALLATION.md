# Instalación (Full o Lite)
1. Descarga y descomprime el ZIP de instalación de la edición elegida. No subas el ZIP entero a ChatGPT.
2. Crea un proyecto privado en ChatGPT; usa memoria exclusiva del proyecto si está disponible y la prefieres.
3. Abre la configuración del proyecto y pega todo el contenido de `PROJECT_INSTRUCTIONS.md` en las instrucciones. Guarda.
4. Sube los archivos de `upload/` individualmente como fuentes. Full contiene 13; Lite contiene 5. No mezcles ediciones. Comprueba el límite de archivos en tu cuenta: https://help.openai.com/en/articles/10169521-projects-in-chatgpt .
5. Abre un chat nuevo y escribe `Main menu`. Prueba `I want to talk to Sunny` y después `Quick start with Nephis` en otro chat. Comprueba que pregunta por la ficha antes de jugar.
6. Para obtener un informe, escribe `End session`, confirma con `Yes, please`. Si no hay herramientas para exportar, usa el mismo chat en texto. Guarda informes y checkpoints fuera del repositorio.

No se instala software en ChatGPT. Python es opcional y local. Las ediciones no se sincronizan con GitHub automáticamente. Lite reduce modularidad y su comportamiento debe probarse. No compartas un proyecto con datos privados.

Para analizar los CSV descargados, consulta [Análisis local](ANALYTICS.md). La herramienta Python está incluida en el ZIP y no se sube a las fuentes de ChatGPT.
