# Installation (Full or Lite)
1. Download and extract the chosen installation ZIP. Do not upload the ZIP itself to ChatGPT.
2. Create a private ChatGPT Project; select project-only memory if available and desired.
3. Open project settings, paste all of `PROJECT_INSTRUCTIONS.md` into project instructions and save.
4. Upload the files in `upload/` individually as project sources. Full has 13 files; Lite has 5. Do not mix editions. Check current plan limits: https://help.openai.com/en/articles/10169521-projects-in-chatgpt .
5. Open a new chat, enter `Main menu`, then `I want to talk to Sunny`. In a separate chat try `Quick start with Nephis` and verify character-sheet approval.
6. For a report, enter `End session` and confirm with `Yes, please`. If export is unavailable, continue in the same text chat. Keep reports and checkpoints outside the repository.

No software is installed in ChatGPT. Python is optional and local. Updates are manual. Lite reduces modularity and needs live behavior testing. Do not share projects containing private records.

To analyse exported CSVs, see [Local analytics](ANALYTICS.md). The Python tool is included in the installation ZIP and should not be uploaded as a ChatGPT source.
