# User guide (quick reference)
The detailed Spanish manual is available at [USER_MANUAL.md](../es/USER_MANUAL.md). Use `Main menu`, `I want to talk to Roxas`, `Quick start with Sunny`, `Show my status`, `Save campaign`, `Continue our adventure`, `Feedback now`, `End session`, `Update character memory`, or `Update learning progress`. Balanced correction is the conversation default; Feedback later is the RPG default. Reports require confirmation after a farewell unless explicitly requested. RPG pause, return to menu and farewell prepare a copyable checkpoint unless declined, independently of report consent. Resume reconciles later confirmed events and asks for missing dynamic state rather than replaying encounters. Save reports and checkpoints privately; paste the checkpoint in a new chat if retrieval fails. This English guide is a summary, not a full translation.
