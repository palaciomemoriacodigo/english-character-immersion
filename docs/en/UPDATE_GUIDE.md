# Update without losing progress

1. Privately back up reports, checkpoints, personalised progress and the previous installation files.
2. Open the [setup website](https://palaciomemoriacodigo.github.io/english-character-immersion/en.html) and read the [changelog](../../CHANGELOG.md).
3. If possible, test the new instructions and single source in a separate private project. Verify conversation, RPG and feedback.
4. Once verified, replace the old instructions and source in your usual project. Keep your chats. Back up any personalised sources and migrate required records manually; never overwrite them with empty templates.
5. If anything fails, retain the old project or restore your previous files. There is no automatic update or synchronisation.

You do not need to reinstall for each conversation.
