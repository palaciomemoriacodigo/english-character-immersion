# Roadmap

- Character conversations with five profiles (Sunny, Nephis, Lelouch, Izaya and Roxas), adaptive English practice and RPG adventures configured for Sunny and Nephis only (Shadow Slave).
- Session feedback, optional local CSV analysis and checkpoint templates.
- Bilingual dark landing, guided one-source installation and reproducible packages.

- Improve continuity, learning feedback and documentation based on actual tests.

- Evaluate a modular RPG environment system, with character-specific settings, ability rules, progression and campaign state for additional characters and worlds.
- Review third-party rights before distributing additional franchise-specific material. No other RPG setting is currently configured.

Future features and version numbers are not commitments. The release scope depends on testing and review. See [CHANGELOG](CHANGELOG.md) and [release checklist](MAINTAINER_CHECKLIST.md).
