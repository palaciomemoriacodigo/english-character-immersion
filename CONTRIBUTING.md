# Contributing
Open an issue with synthetic examples, expected behavior, actual behavior and version/edition. Do not share personal data or third-party assets. Use a feature branch, make small commits, run `python scripts/validate.py` and `python -m unittest discover -s tests`, then open a pull request. For prompt changes run the manual tests in `tests/CONVERSATIONAL_TESTS.md`. Update CHANGELOG and docs. Maintain filename references, source citations and spoiler limits. Only contribute material you have rights to distribute. Original contributions must be compatible with the MIT or CC BY-NC 4.0 scope in LICENSE, as applicable; franchise and third-party material remains excluded and subject to rights review.
