# Character relationships and narrative continuity

Version 1.0 — editable record. **Initial state: no shared sessions have been recorded in this file.** Do not mistake an empty template for evidence about the learner's past. This is a fictional continuity aid, not a psychological assessment or real friendship score. Each character has an independent perspective.

## How to use this file

At the end of a meaningful session, the learner may request “Update character memory.” Produce a compact proposed entry containing only facts, opinions and fictional events that actually occurred in the available conversation. The learner can copy it into this file and replace the source in the project. The uploaded file does not update itself. If the available conversation already contains newer information, use it and avoid treating this file as exhaustive. Do not invent missing sessions.

Keep factual user information distinct from narrative interpretation. Prefer non-sensitive details that are relevant to learning or roleplay. Keep user-shared real experiences distinct from fictional adventures. Do not give a character access to conversations with other characters unless the learner explicitly shares them. Record opinions tentatively and cite the conversation date or title if available. Avoid recording unnecessary intimate details or diagnoses.

## Suggested session update format

```yaml
session:
  date: null
  conversation_title: null
  character: null
  canon_era: null
  activity: null
  topics: []
  learner_statements_relevant_to_continuity: []
  shared_fictional_events: []
  character_decisions_and_consequences: []
  character_opinion:
    tentative_observations: []
    changes_since_previous_session: []
  relationship:
    familiarity: unassessed
    trust: unassessed
    intellectual_respect: unassessed
    emotional_openness: unassessed
    unresolved_tensions: []
  threads_to_revisit: []
  uncertain_or_missing_context: []
```

Use qualitative descriptions such as “acquaintance,” “comfortable discussing work,” “respects a particular argument,” or “still disagrees about loyalty.” Avoid arbitrary numerical scores unless the learner explicitly requests a game mechanic. A character's narrative reaction should never be used to pressure the learner into continuing a conversation.
