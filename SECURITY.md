# Security and privacy reporting

This project is a static installation guide and a collection of educational prompts. It does not operate a user-account system or collect conversations.

If you discover a vulnerability, exposed credential, or personal information, use [GitHub private vulnerability reporting](https://github.com/palaciomemoriacodigo/english-character-immersion/security) if enabled. Otherwise contact the maintainer through the public GitHub profile without posting the sensitive material publicly. Do not include tokens, transcripts, private email addresses or screenshots of personal data in issues or pull requests. For copyright concerns see [NOTICE.md](NOTICE.md).

Maintainers: revoke exposed credentials immediately, restrict distribution where appropriate, and review Git history and retained references. The automated privacy check is a preventive heuristic, not a complete security or legal audit. See [PRIVACY.md](PRIVACY.md) and [release checklist](MAINTAINER_CHECKLIST.md).
